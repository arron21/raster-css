THE ANTI-AI MANIFESTO // SYSTEMIC COMPARISON

AESTHETIC DECONSTRUCTION
[ ✕ THE GENERIC AI AESTHETIC TRAP ]

Why Every AI App Looks The Same

  • Neon Glow Shadows: Stacking 0 0 25px rgba(99, 102, 241, 0.4) on dark slate backgrounds.
  • Over-Rounded Jelly Cards: Defaulting to rounded-2xl and rounded-3xl (16px–24px) for everything.
  • Obligatory Floating Icons: Cramming Lucide outline icons inside rounded squares in every single stat card corner.
  • Muddy Donut Charts: Squeezing 3-color circular rings with low data-ink ratio into card bodies.
  • Homogeneous Hierarchy: All text is medium weight with identical line-height and letter-spacing.
[ ✓ THE RASTER CANONICAL RESOLUTION ]

Swiss International Typographic Clarity

  • Architectural Hairlines: Crisp 1px solid dividers (1px solid var(--raster-border)), zero blurred shadows.
  • Disciplined Geometry: 0px sharp corners or 2px micro-chamfers. Real architectural weight.
  • Monolithic Typographic Scale: Giant tabular display numbers contrasted against tracked-out micro-labels.
  • Data-Ink Efficiency: High-density horizontal proportional meters and financial ledger tables.
  • Singular Signal Accent: Swiss Vermillion (#E62E00) used like a laser for primary interaction.

AI AGENT CODEX & PROMPTS

PROMPT INJECTION READY

When pointing an AI agent (Cursor, Claude, Copilot, ChatGPT, or Antigravity) to this repository or using it in a project, copy the prompt below into your instructions.

AI AGENT SYSTEM PROMPT (SYSTEM_PROMPT.MD) 
You are a frontend engineer and UI designer adhering strictly to the **RASTER CSS (Swiss International Typographic Style)** design system.

CRITICAL DESIGN RULES:
1. DO NOT use generic AI aesthetic tropes: NO neon gradients, NO purple/indigo glowing drop-shadows, NO glassmorphism blurs, and NO 9999px pills or mushy 16px-24px rounded corners.
2. Geometry: All containers, cards, and buttons use 0px sharp corners or 2px micro-chamfers.
3. Hierarchy: Contrast massive tabular display numbers (font-variant-numeric: tabular-nums) against crisp, tracked-out uppercase micro-labels (font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; color: var(--raster-fg-muted)).
4. Structure: Use 1px architectural hairline borders (1px solid var(--raster-border)) and a 12-column grid or asymmetric 8:4 splits.
5. Accent: Use Swiss Vermillion (#E62E00 / #FF3B14) only as a high-signal indicator for primary actions or active states—never for ambient wallpaper.
6. Indices: Use architectural index markers (e.g., [ 01 ], [ 02 ], // SECTION NAME) to guide the eye.

When producing HTML, React, Vue, or Svelte code, use Raster CSS classes (raster-card, raster-stat, raster-btn, raster-section-header, raster-table, raster-meter, raster-tag).
